# 전주 가족여행 플래너

가족 3인(성인 2명 + 초등학생 1명)의 전주 1박 2일 여행 일정을 조정하는 정적 웹 앱입니다.

## 현재 구성

- 시간대별 일정과 날짜별 이동 동선
- 일정 지도(Leaflet + OpenStreetMap)와 Google Maps 길찾기 연결
- 일정 대안 3종, 장소 포함/제외 및 순서 조정
- 방문 전 확인사항, 먹거리 후보, 주차 계획
- 사용자 장소 등록과 사진 첨부
- 일정·사용자 장소는 브라우저 로컬 저장소에 보관

## 실행

1. `index.html`을 내려받거나 GitHub Pages로 배포한 사이트를 브라우저에서 엽니다.
2. 지도 타일과 지도 라이브러리를 위해 인터넷 연결이 필요합니다.
3. 장소 사진과 일정은 해당 브라우저에 저장됩니다. 브라우저 데이터 삭제, 기기 변경, 다른 브라우저 사용 시 데이터가 보존되지 않을 수 있습니다.

> 현재 문서화 기준: 2026-10-09. 운영 데이터·예약 가능 여부·개장 시간은 앱에서 실시간으로 검증하지 않습니다. 방문 전 공식 채널에서 확인하세요.

## 범위와 제한

- 서버 계정, 다중 기기 동기화, 예약 API, 실시간 운영시간 확인은 포함하지 않습니다.
- 이동 시간은 계획용 추정치일 수 있으며, 실시간 교통량을 반영하는 경로 최적화 엔진이 아닙니다.
- 방문지의 운영 정보는 변동될 수 있습니다. 실제 여행 당일에는 공식 정보와 현장 안내를 우선합니다.
