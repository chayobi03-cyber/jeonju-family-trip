# 인수·회귀 테스트 기준

- 기준일: 2026-10-09
- 상태 표기: **미실행**은 테스트가 아직 브라우저에서 검증되지 않았음을 뜻한다.
- 이 문서는 테스트 설계 기준이다. 실행 결과로 잘못 표시하지 않는다.

## 실행 절차

1. 최신 `index.html`을 Chrome Android와 데스크톱 Chrome에서 연다.
2. 새 브라우저 프로필에서 핵심 흐름을 검사한다.
3. 사용자 장소 1개를 생성하고 사진 2장을 추가한다.
4. 일정 변경 후 새로고침하고, 사진·일정 복원을 확인한다.
5. 네트워크를 끄거나 Leaflet/타일 요청을 차단해 텍스트 열람과 오류 안내를 점검한다.
6. 결과, 브라우저 버전, 날짜, 발견된 이슈를 표의 상태에 기록한다.

## 완료 기준

- P0 항목 모두 통과.
- P1의 저장·보안 관련 AT-11~AT-17, AT-20 통과.
- 모바일 화면에서 주요 흐름 사용 가능.
- 실제 방문지 영업시간·예약·주차·공연 여부를 앱이 실시간 검증한다고 오해할 문구가 없음.
